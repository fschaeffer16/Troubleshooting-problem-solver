# Learnings

Mistakes made and the lesson, so they are not repeated.

- 2026-11-17: Sites added in the environment settings while a session is running did not become reachable in that session (tested twice, several minutes apart). Lesson: after Frank adds a site, test one page before saying research can start, and say plainly if the session cannot see the change.
- 2026-11-17: The thread told Frank the running session could not open the newly added sites. That was based on one tool. A shell test later reached four of them. Lesson: before saying a site is unreachable, test it with more than one tool, and say which tool failed.
